## 注意: 観測後も残すと1日約200〜230円

ALB + WAF + IPv4×3 + EC2 は「置いておくだけ」で約 $1.4/日 かかる。
計画書どおり分析期間（1週間）中も残すと +1,400円程度になり、予算 1,000円を超える。

→ **観測中にコンソール学習・スクショを済ませ、観測終了後すぐに honeypot スタックを destroy する**（`docs/03-teardown-checklist.md` 段階1）。
ログ（CloudWatch Logs / S3）と GuardDuty は base スタックに残るので分析は続けられ、こちらは月数円程度。

## 使わなかったもの（高いので）

| 構成案 | 48時間の追加費用 | 不採用理由 |
|---|---|---|
| NAT Gateway（EC2 をプライベートサブネットへ） | 約 $3（450円）+ データ処理 | 予算の半分近い。EC2 にパブリックIPを付け、受信は SG で ALB からのみに限定 |
| SSM 用 VPC インターフェースエンドポイント ×3 | 約 $2（300円） | 同上 |
| HTTPS（443） | 証明書は無料だが独自ドメインが必要 | ドメインがあれば `acm_certificate_arn` を指定すれば有効化できる |

## 予算の見張り方

- AWS Budgets（base スタックで作成）: 当月実績 50% / 80%、予測 100% でメール
  - アカウント全体のコストが対象。他にも課金中のリソースがあるアカウントなら `budget_usd` を調整
  - 請求データは数時間〜1日遅れて反映されるため、**アラートは「止める合図」で、自動停止はしない**
- 1日1回: Billing → 請求書（当月の速報値）を目視
- Cost Explorer: 日次・サービス別で見る。反映は約24時間遅れ。記事用の実費スクショは撤収2〜3日後に
